# Upbit Pro Algo-Trader

> **업비트(Upbit) OpenAPI 기반 고성능 24시간 퀀트 코인 자동매매 데스크톱 애플리케이션**

Upbit Pro Algo-Trader는 전문 트레이더와 퀀트 투자자를 위한 다중 전략 기반 암호화폐 자동매매 프로그램입니다. 초저지연 시세 수집, 7대 퀀트 전략 엔진(단일/앙상블), 시장 레짐(Market Regime) 분석, 3중 리스크 제어, 호가창 깊이 분석 기반 슬리피지 방어, 분할 주문(TWAP), 미체결 자동 복구(Reconciliation), 페이퍼 트레이딩(모의투자) 및 백테스팅 엔진을 지원합니다.

## 주요 특징

- **초저지연 실시간 시세 및 체결 피드**: WebSocket 기반 실시간 호가/체결 데이터 및 Private 이벤트(`myOrder`, `myAsset`) 즉각 수신
- **공식 최신 REST 클라이언트 내장**: SHA512 JWT 인증 서명, 엔드포인트 그룹별(quotation, exchange, order) 실시간 Rate Limit 추적 및 지수 백오프/재시도
- **7대 퀀트 전략 & 앙상블 엔진**:
  - 변동성 돌파(Volatility Breakout), 돈치안 채널(Donchian Breakout), EMA 크로스 추세추종(EMA Cross Trend), 시계열 모멘텀(Time-Series Momentum), RSI 평균회귀(RSI Reversion), 볼린저 밴드 평균회귀(Bollinger Reversion), Z-Score 평균회귀(Z-Score Reversion)
  - 단일 전략 모드 및 가중 합산 앙상블(Ensemble) 모드 지원
- **글로벌 시장 레짐(Market Regime) 분석**:
  - 업비트 상위 코인 시장 폭(Market Breadth), 비트코인 추세/변동성, 공포/탐욕 지수(Fear & Greed Index), 글로벌 ETF Flow 종합 분석
  - 레짐 점수에 따른 신규 진입 자동 필터링 및 리스크 익스포저 스케일링 (0.5x ~ 1.15x)
- **다층 리스크 관리 & 포지션 사이징**:
  - 계좌 리스크 예산(Risk Budget) 및 ATR 기반 포지션 사이징
  - 전략 성과 기반 켈리 기준(Kelly Criterion) 보정
  - 드로우다운 상태 머신(Normal / Caution / Defense / Halt) 기반 비중 축소 및 거래 중단
  - 일일 최대 손실 제한, 연속 손실 제한, 포트폴리오 상관집중도(Correlation) 제한
- **스마트 주문 실행 & 슬리피지 방어**:
  - 10단계 원화 호가단위(Tick Size) 규칙 완벽 준수
  - 호가창 스프레드 및 잔량 깊이(Depth) 사전 점검(Orderbook Guard)으로 슬리피지 방어
  - 단일 시장가(`single_market`), 시간분할 주문(`twap_market`), 최유리 지정가(`best`) 실행
- **미체결 주문 감지 및 자동 복구 (Order Reconciliation)**:
  - 시스템 재시작 시 거래소 잔존 주문 자동 복구 및 수동검토 큐(Manual Review Queue) 이관
  - 주문 상태 영속화(DPAPI 암호화 지원)
- **안전한 모의투자(Paper Trading) & 백테스팅**:
  - API 로그인 없이도 시드 머니로 실시간 시세를 이용한 모의투자 가능 (수수료/슬리피지 반영)
  - 과거 OHLCV 데이터 기반 백테스팅 및 인터랙티브 HTML 성과 리포트 자동 생성
- **보안 및 알림**:
  - Windows DPAPI 기반 API Key 암호화 보관 (`upbit_settings.json` schema v2)
  - 체결 및 시스템 이벤트를 위한 Discord 웹훅 연동 및 Windows 트레이 알림

## 시스템 요구사항

- **운영체제**: Windows 10 / 11 (권장), macOS, Linux
- **Python**: Python 3.10 이상
- **주요 라이브러리**:
  - `PyQt6 >= 6.0` (GUI 프레임워크)
  - `pyupbit >= 0.2.30`
  - `pandas`, `numpy` (데이터 분석 및 지표 계산)
  - `requests`, `websocket-client >= 1.6.0` (네트워크 및 웹소켓 통신)
  - `PyJWT >= 2.8.0`, `cryptography` (업비트 인증 및 보안)

## 빠른 시작 가이드 (Quick Start)

처음 프로그램을 실행할 때는 **모의투자(Paper Trading)** 모드로 먼저 시스템을 둘러보는 것을 적극 권장합니다.

```
[1. 프로그램 실행] ➜ [2. 페이퍼 모드 확인] ➜ [3. 감시 코인 설정] ➜ [4. 매매 시작]
```

1. **무로그인 모의투자 시작**:
   - 상단 API Key를 입력하지 않아도 기본적으로 **페이퍼 트레이딩**이 지원됩니다.
   - [고급 설정] 탭 ➜ [모의투자 (Paper Trading)] 그룹에서 `페이퍼 트레이딩 활성화` 및 `로그인 없이 시작 허용`이 켜져 있는지 확인합니다.
   - [전략 설정] 탭 하단의 `🚀 전략 분석 및 매매 시작` 버튼을 클릭하면 10,000,000원의 가상 시드로 즉시 모의 매매가 시작됩니다.
2. **실거래(Live) 전환 방법**:
   - 업비트 웹사이트(마이페이지 ➜ Open API 관리)에서 **Access Key**와 **Secret Key**를 발급받습니다. *(자산조회, 주문조회, 주문 권한 필수 / 출금 권한은 반드시 제외하세요)*
   - 상단 대시보드의 Access / Secret 입력칸에 키를 입력하고 `🔌 시스템 접속` 버튼을 누릅니다.
   - [고급 설정] 탭에서 `페이퍼 트레이딩 활성화`를 체크 해제합니다.
   - [전략 설정] 탭에서 원하는 리스크 설정을 마친 후 `🚀 전략 분석 및 매매 시작`을 누릅니다.

### 1. 대시보드 (Dashboard) & API 연동

- **Access / Secret Key**: 업비트 API 키를 입력합니다. (키는 Windows DPAPI를 통해 암호화되어 안전하게 보관됩니다.)
- **🔌 시스템 접속**: API 키 검증 및 계좌 잔고를 동기화합니다.
- **💰 주문가능금액 / 📈 당일 실현손익**: 실시간 KRW 잔고와 당일 확정 손익을 표시합니다.
- **연결 상태 표시등**: 연결 대기(황색), 실거래 연결(녹색), 모의투자 모드(청색) 등 현재 시스템 연결 상태를 나타냅니다.

### 2. 전략 설정 탭 (기본 매매 설정)

가장 핵심적인 거래 파라미터를 설정하는 화면입니다.

- **📋 감시 코인**: 모니터링 및 자동매매를 진행할 마켓 코드를 쉼표(,)로 구분하여 입력합니다. (예: `KRW-BTC,KRW-ETH,KRW-SOL,KRW-XRP`)
- **🕐 캔들 간격**: 전략 분석 및 지표 산출에 사용할 캔들 주기를 선택합니다. (`1분`, `5분`, `15분`, `30분`, `1시간`, `4시간`, `일봉`)
- **💵 종목당 투자비중 (%)**: 총 자산 대비 1개 종목에 진입할 때 베팅할 비율을 지정합니다. (기본값: `10.0%`)
- **📐 변동성 K값**: 래리 윌리엄스 변동성 돌파 전략의 K 계수입니다. (기본값: `0.4`, 범위: `0.1 ~ 1.0`)
  - 목표 매수가 = 당일 시가 + (전일 고가 - 전일 저가) × K
- **🎯 TS 발동 수익률 (%)**: 트레일링 스탑(Trailing Stop) 추적을 시작할 기준 수익률입니다. (기본값: `5.0%`)
- **📉 TS 하락폭 (%)**: 최고 수익률 달성 후 고점 대비 허용 하락폭입니다. 이 하락폭에 도달하면 이익 보존을 위해 즉시 시장가 매도합니다. (기본값: `2.0%`)
- **🛑 절대 손절률 (%)**: 매수가 대비 하락 시 무조건 손절매를 집행할 기준입니다. (기본값: `3.0%`)
- **일괄 매수 / 매도 버튼**:
  - `📤 일괄 매도`: 현재 보유 중인 모든 암호화폐를 즉시 전량 시장가 매도합니다.
  - `📥 일괄 매수`: 입력된 감시 코인들을 현재 예수금으로 균등 분할 매수합니다.
  - `완료 후 자동매매 시작`: 일괄 작업 완료 후 자동으로 감시 엔진을 시작합니다.
- **💾 설정 저장 / 🚀 매매 시작 / ⏹️ 매매 중지**: 현재 설정을 `upbit_settings.json`에 저장하고 자동매매를 제어합니다.

### 3. 고급 설정 탭 (고급 기능 완벽 분석)

더 정교한 퀀트 알고리즘과 리스크 관리를 구성할 수 있습니다.

#### ① 보조지표 진입 필터 (Indicator Filters)
- **RSI 필터**: 과매수 구간 매수 방지 (기본 기간: 14, 상한선: 70 이하일 때만 매수)
- **MACD 필터**: MACD선이 Signal선 위에 위치한 상승 추세일 때만 매수
- **거래량 필터**: 최근 20개 캔들 평균 거래량 대비 N배(기본 1.5배) 이상 터졌을 때만 진입
- **볼린저 밴드 필터**: 상단 밴드 이탈 방지

#### ② 전략 엔진 & 앙상블 (Strategy Engine)
- **전략 모드**:
  - `single`: 7대 전략 중 1개를 선택하여 해당 전략 신호로만 매매
  - `ensemble`: 선택된 복수 전략의 시그널 점수를 가중 평균하여 임계 점수(예: 60점) 이상일 때만 진입
- **7대 지원 전략**:
  1. `volatility_breakout`: 변동성 돌파 + MA5 추세
  2. `donchian_breakout`: 돈치안 채널 상단 돌파
  3. `ema_cross_trend`: 지수이동평균(EMA 12/26) 골든크로스 및 기울기
  4. `time_series_momentum`: 20개 캔들 시계열 모멘텀
  5. `rsi_reversion`: RSI 30 이하 과매도 및 볼린저 하단 반등
  6. `bollinger_reversion`: 볼린저 밴드 하단 이탈 후 복귀
  7. `zscore_reversion`: 가격 Z-Score 통계적 극단치 반등
- **엔진 게이트 정책 (`engine_gate_policy`)**:
  - `legacy_first`: 기존 목표가/MA5 돌파를 기본 통과한 후 전략 점수 검증
  - `strategy_aware`: 추세추종 전략은 돌파 조건 적용, 평균회귀 전략은 과매도 조건 적용
  - `engine_only`: 전략 엔진의 독자 점수만으로 진입 결정

#### ③ 정밀 리스크 관리 (Risk Management & Sizing)
- **리스크 예산 사이징 (Risk Budgeting)**: 거래당 허용 계좌 손실율(예: 0.5%)과 ATR 변동성 손절폭을 기반으로 주문 수량을 자동 계산
- **켈리 기준 (Kelly Criterion)**: 최근 실현된 승률과 손익비를 바탕으로 베팅 비중을 동적으로 보정 (Kelly Scale 0.25x 등)
- **드로우다운 상태 머신 (Drawdown State Guard)**:
  - 계좌 낙폭에 따라 4단계 상태 자동 전환 (`normal` ➜ `caution` ➜ `defense` ➜ `halt`)
  - 낙폭 심화 시 신규 진입 비중을 단계별 축소하거나 매매를 전면 중단하여 원금 보호
- **변동성 타겟팅 (Volatility Targeting)**: 시장 변동성이 커지면 포지션을 줄이고, 낮아지면 늘려 포트폴리오 변동성을 일정 수준으로 유지

#### ④ 주문 실행 모델 & 슬리피지 방어 (Execution & Slippage)
- **호가창 가드 (Orderbook Guard)**: 매수 직전 호가 스프레드가 설정값(예: 40 bps)보다 크거나 매도 잔량이 부족하면 주문을 보류하여 체결 슬리피지 방지
- **실행 모드 (Execution Mode)**:
  - `single_market`: 즉시 단일 시장가 주문
  - `twap_market`: 대량 주문 시 지정된 시간 간격(예: 8초)으로 N회(예: 3회) 분할하여 충격 비용 최소화

#### ⑤ 시장 레짐 엔진 (Market Regime Engine)
- 글로벌/시장 전체의 건전성 점수(0~100점)를 실시간 산출합니다.
- 점수가 기준치(기본 55점) 미만인 하락장/불안정장에서는 신규 매수를 자동으로 차단합니다.
- 레짐 점수에 따라 주문 금액을 0.5배, 0.75배, 1.0배, 1.15배로 자동 조절합니다.
- 외부 데이터 수신 실패 시 안전을 위해 신규 매수를 차단하는 `fail_closed` 모드를 지원합니다.

#### ⑥ 모의투자 (Paper Trading) & 알림 (Discord)
- **페이퍼 트레이딩**: 가상 자본금(Seed), 모의 수수료(5 bps), 모의 슬리피지(5 bps)를 설정하여 실거래 전 검증
- **Discord 웹훅**: 체결 알림, 손절/익절 알림, 시스템 에러를 디스코드 채널로 실시간 전송

### 5. 운영 및 수동검토 큐 (Ops Tab)

실거래 환경에서 발생할 수 있는 네트워크 불안정, 타임아웃, 거래소 점검 등의 예외를 안전하게 관리합니다.

- **거래소 미체결 주문 자동 감지**: 프로그램 시작 시 거래소에 남아있는 미체결 주문을 감지하여 안전 상태로 등록합니다.
- **수동검토 큐 (Manual Review Table)**: 주문 응답 지연이나 타임아웃으로 상태 확인이 필요한 주문을 별도 큐에 적재합니다.
- **운영 액션**:
  - `🔄 새로고침`: 현재 수동검토 대기열 갱신
  - `🔁 재조회`: 거래소 API를 통해 실제 체결 여부를 즉시 다시 확인
  - `✅ 해제`: 검토 완료 후 대기열에서 안전하게 제거

  - 수수료(0.05%) 및 슬리피지 반영
  - 총 수익률, 최대 낙폭(MDD), 샤프 비율(Sharpe Ratio), 소르티노 비율(Sortino Ratio), 승률, Profit Factor 자동 계산
  - 인터랙티브 HTML 리포트(`backtest_report.html`) 자동 생성 및 브라우저 출력

- **실행 방법**: 상단 메뉴 [도구] ➜ [📊 거래 분석 리포트]
- 저장된 `trade_history.json` 데이터를 기반으로 상세 매매 성과 분석 리포트를 생성합니다.

### 프리셋 매니저

투자 성향에 맞춘 기본 프리셋을 제공하며, 사용자 정의 설정을 프리셋으로 저장/불러오기할 수 있습니다.

- **공격형 (Aggressive)**: K=0.5, 높은 비중(15%), TS 시작 3.0%, 앙상블 전략 활용
- **균형형 (Normal)**: K=0.4, 표준 비중(10%), TS 시작 5.0%, 손절 3.0%
- **보수형 (Conservative)**: K=0.3, 낮은 비중(5%), TS 시작 7.0%, 손절 2.0%, RSI 역추세 중심
- **커스텀 프리셋**: 현재 UI에 입력된 모든 파라미터를 원하는 이름으로 저장하고 원클릭으로 적용 가능

### 시스템 트레이 및 백그라운드 구동

- **최소화 기능**: 윈도우 창 닫기(X) 시 프로그램이 종료되지 않고 시스템 트레이로 최소화되어 24시간 중단 없는 매매를 지원합니다.
- **트레이 메뉴**: 트레이 아이콘 우클릭으로 매매 시작/중지 및 프로그램 완전 종료(`force_quit`)가 가능합니다.
- **자동 시작 & 자동 접속**: Windows 시작 시 자동 실행 및 시작 시 API 자동 접속 옵션을 지원합니다.

## 프로젝트 아키텍처

Upbit Pro Algo-Trader는 모듈 간 결합도를 낮추고 유지보수성을 극대화한 구조로 설계되어 있습니다.

```txt
upbit_autotrader/
├── app/                  # 애플리케이션 진입점, 부트스트랩, 런타임 스레드 라이프사이클
├── controllers/          # UI, 매매, 설정, 히스토리, 일괄작업 Facade 컨트롤러
│   ├── trading_parts/    # 주문, 체결, 포지션, 리스크, 신호, 수명주기 세부 로직
│   └── ui_parts/         # 레이아웃, 대시보드, 전략 탭, 고급 설정 탭 빌더
├── core/                 # Config 전역 설정 상수 및 기본값 정의
├── services/             # 업비트 REST 클라이언트, 보안(DPAPI), 주문 서비스, Rate Limit 제어
├── strategies/           # 7대 퀀트 전략 카탈로그, 앙상블 엔진, 메타 시그널
├── risk/                 # 포지션 사이징(Risk Budget, Kelly), 포트폴리오 리스크 제어
├── execution/            # 단일/TWAP 실행 모델, 호가창 가드, 미체결 복구 저장소
├── market_regime/        # 시장 폭, BTC 모멘텀, 공포탐욕지수 기반 전역 레짐 엔진
├── runtime/              # 실시간 WebSocket 가격 스레드 및 시장 레짐 백그라운드 스레드
├── analytics/            # 거래 통계 분석 및 HTML 리포트 생성기
├── backtesting/          # 과거 데이터 기반 퀀트 백테스팅 시뮬레이터
├── notifications/        # Discord 웹훅 및 시스템 알림 관리자
└── ui/                   # 다이얼로그(설정, 프리셋, 백테스트, 긴급청산) 및 스타일시트
legacy_wrappers/          # 하위 호환성을 위한 레거시 모듈 import 래퍼
tests/                    # 기능, 안정성, 리스크, 회귀 방지 단위/통합 테스트
```

## 설정 파일 및 로컬 데이터

프로그램 실행 시 루트 디렉토리에 다음 파일들이 자동 생성 및 관리됩니다.

- `upbit_presets.json`: 사용자 정의 전략 프리셋
- `trade_history.json`: 매매 체결 이력 및 PnL 기록
- `reconciliation_state.json`: 미체결/대기 주문 복구 상태 저장 파일
- `strategy_performance.json`: 전략별 승률/기대값 통계
- `logs/`: 시스템 실행 로그 및 주문 라이프사이클 로그 (`logs/order_lifecycle.jsonl`)

## 실전 운영 시 주의사항

1. **페이퍼 트레이딩 우선 검증**: 실전 매매를 시작하기 전, 반드시 최소 수일간 모의투자(Paper Trading) 모드로 주문 실행, 수수료, 슬리피지 및 전략 신호를 검증하세요.
2. **API 키 권한 관리**: 업비트에서 API 키를 발급받을 때 **출금 권한은 절대 부여하지 마세요.** (자산조회, 주문조회, 주문 권한만 필요)
3. **미체결 주문 확인**: 프로그램이 비정상 종료되더라도 거래소에 이미 제출된 미체결 주문은 취소되지 않을 수 있습니다. 재시작 후 `운영/수동검토` 탭과 업비트 앱에서 미체결 내역을 확인하세요.
4. **시장 레짐 안전 모드**: 급변하는 시장에서 보수적으로 운용하려면 [고급 설정] ➜ [시장 레짐]에서 `Stale/오류 시 진입 차단 (fail_closed)` 옵션을 켜두는 것을 권장합니다.
5. **거래소 점검 시간**: 업비트 정기 서버 점검 시간에는 API 통신이 일시 중단될 수 있습니다.
